# CRUD 

🚀 **CRUD Application** - A simple project built with **Vanilla JavaScript, HTML, and CSS**, featuring **Create, Read, Update, and Delete (CRUD)** functionality. This project uses **LocalStorage** for data persistence and is deployed using **Surge**.

## 📌 Features

- ✅ Add new items
- 📄 Read existing items
- ✏️ Update items
- ❌ Delete items
- 💾 Data saved in **LocalStorage** for persistence
- 🎨 Styled with **CSS** for a professional look
- 🌑 Dark theme support for better user experience
- 🌍 **Deployed with Surge** for easy access
